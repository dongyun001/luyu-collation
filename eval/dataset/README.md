## 选段从哪儿来（2026-10-14 补，这就是"怎么找"那一步）

### 一、文本（底本）的来源

| 来源 | 适合拿什么 | 注意 |
|---|---|---|
| **中国哲学书电子化计划**（ctext.org） | 先秦两汉诸子、史书全文，可检索定位到篇 | 复制后要核对一遍标点 |
| **维基文库**（zh.wikisource.org） | 公共领域全文，按篇分页好取 | 部分条目有后人校改，取"正文"版本页更稳 |
| **国图「中华古籍资源库」/ 日本内阁文库 / 国立国会图书馆 / 国际敦煌项目 IDP** | **书影**（影印页）—— 天然 OCR 错误的原料 | 这一路只管影像，文本要自己 OCR |

三条硬要求：`origin` 要写成**能查的版本出处**（"《史记·货殖列传》（中华书局点校本）"比"史记"好，
"据 ctext 电子本（底本为武英殿本）"比"网上下载"好）；底本用**公共领域**文本，不要直接把
现代点校本的标点与校记正文当底本（点校本有版权）；引用旧校勘记作为**异文依据**属于合理使用，注明出处即可。

### 二、选什么篇目：小心"名篇效应"（这条比配额更容易毁掉指标）

中学课本里的名篇，模型很可能**背过**——它答对靠的是记忆，不是校勘能力，指标会虚高，
而评委问"你的测试集是不是都是常见篇目"时很难答。建议**至少一半**取自不算热门的篇目。候选（均公共领域）：

- 史：《史记·货殖列传》《汉书·食货志》《后汉书·党锢列传》《三国志·魏书·武帝纪》裴注
- 子：《荀子·天论》《韩非子·难一》《论衡·问孔》《潜夫论·实贡》《颜氏家训·勉学》《齐民要术·序》
- 经与经注：《左传》隐公/僖公某年、《孟子·滕文公》《礼记·月令》
- 笔记 / 地志 / 文论：《世说新语·雅量》《洛阳伽蓝记》《水经注·江水》《文心雕龙·情采》《酉阳杂俎》

**一段能吃多个点**：200–500 字里通常放得下 3–5 个注入点、1–3 个天然 OCR 错误、1–3 处异文。
所以 60 点的配额 **10 段就够，不需要 60 段**。

### 三、五类各自的素材去哪取（按省力排序）

1. **讹字（≥10）**：直接注入形近替换即可——伐/代、未/末、己/已、祟/崇、戌/戍、卮/危、析/折。
2. **衍文（≥10）**：把双字词误重一字（`舍去`→`舍舍去`、`可以`→`可可以`），或虚字误重。
3. **脱文（≥10）**：脱虚字（之 / 为 / 而 / 其 / 以）。
4. **通假（≥10）**：**不注入**，在原文里挑现成的通假用字——蚤/早、说/悦、亡/无、见/现、直/值、
   信/伸、有/又、女/汝。古籍里很常见，一段常能取 1–2 个；这类需要一点点文献学判断，别标错。
5. **异文（≥10）**：唯一**必须有版本依据**的一类，三个可靠来源——
   - 旧校勘记（本身是公共领域）：阮元《十三经注疏校勘记》、王念孙《读书杂志》、
     王引之《经义述闻》、《史记》三家注；
   - 敦煌写本 / 宋元刻本的释文或书影（IDP、国图、内阁文库）；
   - 有明确记载的名篇异文：帛书《老子》「道可道也，非恒道也」、宋本《李太白文集》「床前看月光」、
     敦煌本《将进酒》「天生吾徒有俊才」、《庄子》「北冥」/「北溟」。

   `note` 要写成**能查的**（「敦煌本《将进酒》作…」「阮元《校勘记》云…」），
   写不出出处的点**不要用**——`hasEditionEvidence` 就是为这种情况设的（见下文第 7 条）。
   **省力提示**：10 处异文不必来自 10 段，一段名篇常有 2–3 处可查异文。

### 四、天然 OCR 错误怎么来（本项目 OCR 尚未实现，得用外部工具）

`docs/EVAL.md §2.2` 要求每段都有"由 OCR 工具识别真实书影产生"的错误。我们的 OCR（F7）还没做，所以这一步走外部：

1. 取一页公共领域**书影**（国图 / 内阁文库 / IDP）；
2. 用任一 OCR 跑一遍（识典古籍、PaddleOCR、各云厂商的免费额度都行）；
3. **错误原样保留，不要顺手改对**，逐条标 `source: "ocr"`。

这一步别省：它是"错误分布可信"的证据，也是答辩必问点。真来不及就如实降级——先交注入类指标，
OCR 类作为第二批补，并在报告里写明哪些来源尚未覆盖。

## 填的时候按这个顺序

1. **选段**：公共版权古籍通行本，每段 **200–500 字**，共 **10 段**（v1）。
   - **避开《论语》学而篇**：它是校勘 Prompt 的 few-shot 示例，放进来会污染评测。
     `self_check` 会认出 few-shot 片段并报错。
   - **体裁分散**（史书 / 诸子 / 骈文 / 笔记各来几段）：10 段同一部书，指标只反映一种文体。
   - **保持一整行**：换行符也按 1 个字计入，多行会高估字数、也让选段不再是一段连续的文。
2. **每段同时具备两类错误**：天然 OCR 错误（真实分布）+ 人工注入错误（保证五类都有样本）。
   - 讹字：形近替换（`伐`→`代`）　衍文：误重一字（`舍去`→`舍舍去`）　脱文：脱虚实字（`其名为鲲`→`其名鲲`）
   - **通假不注入**：通假不是错误而是用字现象，样本取自原文本身（`source` 填 `inherent`）
   - 异文：换成**有版本依据的**他本写法，并在 `note` 里注明依据
3. **不要手数索引**——这是标注里唯一的系统性错误来源。把选段存成**标记文件**
   （放 `docs/eval/annotate/`，过程材料不入库），用 `[[原文|权威写法|类型|来源|备注]]` 标出每个点，
   索引由 `eval/mark_to_labels.py` 算：

```bash
python -m eval.mark_to_labels docs/eval/annotate/case-001.marked.txt    # 先人眼核对区间，不写盘
python -m eval.mark_to_labels docs/eval/annotate/*.marked.txt --write   # 确认后写进数据集
```

   标记文件顶部可写元信息（`# caseId: case-001` / `# origin: 《左传·庄公十年》（杨伯峻注本）`），
   `caseId` 也能从文件名推断（`case-001.marked.txt`）。后三段可省：只写 `[[原|改]]` 时类型留作
   「待定」——脚本**不猜类型**（猜错会污染逐类指标，而自检查不出来）；`来源` 默认 `injected`；
   **异文没写备注时 `hasEditionEvidence` 自动为 `false`**（没给别本依据就等于没有依据）。
4. **配额**：五类各 **≥10**，总量 **≥60**。
5. **标注 `start`/`end` 用左闭右开区间**，且必须满足 `source[start:end] == original`。
   上面那条命令保证了这一点，但仍要跑自检兜底：

```bash
python -m eval.self_check eval/dataset/     # 不通过就别往下走
```

6. **异文类的 `expectedSuggestion` 必须填别本写法**，不能与 `original` 相同
   （与 `docs/API.md §2` 的契约同一条；`self_check` 会拦）。
7. **`hasEditionEvidence`**：该点能否凭版本判定。异文类填 `false` 时，模型报它按**存疑**处理
   （既不算检出也不算误报，见 `docs/EVAL.md §3.5`）。
8. **两人复核**：标注人自检后，第二人至少抽 **20%** 复核。
   这一步机器验不了，请在报告里写明复核人编号与抽样比例。

## 填完怎么确认

```bash
python -m eval.self_check eval/dataset/            # 必须 0 error
python -m eval.self_check eval/dataset/ --json     # 机器可读，供脚本/CI 调用
```

输出里会带逐类配额与总量；只有 `warn`（复核比例提醒）是正常的。

## 不许做的事

- **不许把测试夹具当基准**：`eval/tests/fixtures/` 下的东西只用于验证脚本，不是证据。
- **不许为了指标好看而删难例**：漏报的点要留着，它就是召回率的分母。
- **不许改口径来迁就结果**：口径改动只走 `docs/EVAL.md`，并说明理由与影响。
